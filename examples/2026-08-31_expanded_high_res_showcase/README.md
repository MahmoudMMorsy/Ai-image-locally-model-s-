# NanoPixel AI Showcase: Expanded High-Resolution Corpus (2026-08-31)

This directory contains synthesized character sprites and poster designs generated after fine-tuning NanoPixel AI models (NanoPixel-v1, NanoPixel XL0_2, NanoPixel 3A XL, and Poster Generator 256) on the expanded dataset of 2,534 pixel art samples.

## Showcase Contents:
- **39 Game Boy / NES / GBA Style Character Sprites**: Distinct pixel art characters covering cyberpunk hackers, elven rangers, knights, dragons, and mechas.
- **10 Bilingual Arabic/English Poster Samples**: 256x256 posters with verified right-to-left Arabic text direction and high-contrast retro artwork.
- **ONNX Model & Android Compatibility**: All models export to ONNX runtime for sub-second CPU & Android local inference.
