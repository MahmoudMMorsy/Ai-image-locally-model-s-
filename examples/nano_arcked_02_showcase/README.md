# NanoArcKed-02 Showcase Outputs

This folder contains 64x64 pixel art character outputs generated by `NanoArcKed-02`.

## Features Included:
- **Text-to-Image (T2I)** generation
- **Image-to-Image (I2I)** character refinement
- **Animated GIF** and **Sprite Sheet** generation
- **Game Boy** (4-color green) & **NES** (16-color retro) palette quantization
