# Comprehensive Trained Pixel Art & Poster Showcase (2026-09-12)

This directory contains real training dataset fine-tuning outputs generated on CPU without GPU requirements:

## 🎮 Features & Quantized Palettes
- **Game Boy Retro Palette:** 4 iconic green shade quantization (`*_gameboy.png`).
- **NES Retro Palette:** 16-color 8-bit classic gaming quantization (`*_nes.png`).
- **Signature Palette:** 32-color crisp pixel art quantization (`*_signature.png`).
- **Action Sprite Sheets:** 4-frame 256x64 run animations (`*_spritesheet_*.png`).
