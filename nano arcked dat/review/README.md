# Visual review and rights workflow

The dataset is intentionally split into two lanes.

## 1. Mirror lane

Assets with an explicitly redistributable license can be downloaded into the repository and shown in the GitHub review gallery.

## 2. Rights-research lane

For paid assets, game sprite archives, protected images, Pinterest pins, and image-search results:

- record the exact source page
- record creator/artist when available
- record title/game/universe
- record the exact license or mark it unknown
- record price and purchase URL when applicable
- record AI/ML permission separately
- keep the candidate as purchase_required, rights_holder_required, or unknown until verified
- do not treat a search result, repost, or Pinterest pin as the copyright source
- do not copy protected binaries into this public repository before the required rights are established

## Review decisions

- keep: visually useful and rights path is acceptable
- maybe: visually useful but rights/license needs investigation
- delete: not useful
- excluded: violates the project's collection filters or creator restrictions

The final decision stays with the dataset owner. The collector records evidence; it does not decide what should be licensed.
