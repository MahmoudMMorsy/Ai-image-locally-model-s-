# License policy

## Primary pool

CC0 / Public Domain assets are the preferred pool.

## Attribution licenses

CC-BY assets may be collected only when the exact author and source page are retained.

## Share-alike / copyleft

CC-BY-SA, GPL, OGA-BY and similar assets are kept in a separately identifiable pool with their exact license. They are not rewritten as CC0.

## Unknown / restricted

Unknown-license assets, paid assets without an acquired license, and assets with explicit AI/ML restrictions are excluded from the redistributable collection.

## Religious-content exclusion

The collector uses conservative filename/path/source-text filters for the project's requested exclusions. Automated text filtering cannot guarantee visual detection. Anything ambiguous is quarantined for manual review rather than treated as cleared.
