# قاعدة تصنيف الشخصيات (Character Taxonomy)

نظام تصنيف كامل لصور تدريب نماذج التوليد، مع **حظر صريح** لتصوير المقدسات الإسلامية.

## الملفات

| ملف | الوظيفة |
|-----|---------|
| `character_taxonomy.json` | محاور التصنيف وقيمها (نوع، جنس، دور، ثقافة، أسطورة، أسلوب...) |
| `label_schema.json` | مخطط كل سجل صورة تدريب + مثال |
| `blocked_entities.json` | قائمة المحظورات: الله، الأنبياء، المرسلون، الصحابة... |
| `safety.py` | فحص البرومبت/التسمية ورفض المحظور |
| `labels_db.json` | قاعدة التسميات الفعلية |
| `bootstrap_labels.py` | إنشاء تسميات أولية من مجلد الصور |

## محاور التصنيف الرئيسية

1. **media_type** — بيكسل، أنمي، واقعي، 3D...
2. **species_or_form** — بشري، روبوت، وحش، إلف...
3. **gender_presentation** — ذكر / أنثى / غير محدد...
4. **age_band** — طفل / بالغ / مسن...
5. **body_type** — نحيف / عضلي / ضخم...
6. **role_archetype** — محارب، ساحر، شرير، بطل...
7. **setting_era** — وسيط، سايبربانك، حديث...
8. **culture_region** — شرق أوسطي، شرق آسيا، غربي...
9. **source_domain** — لعبة، أنمي، أسطورة، تاريخي، OC...
10. **mythology_family** — يوناني، نورسي، مصري قديم... (**بدون** المقدسات الإسلامية)
11. **palette_mood / pose_view / equipment_tags**

## سياسة الحظر

يُرفض أي تدريب أو توليد يتضمن:

- تصوير **الله**
- **الأنبياء والمرسلين** (محمد، موسى، عيسى، إبراهيم، ... وجميعهم)
- **الصحابة** وأمهات المؤمنين وآل البيت في السياق المقدس

الفحص يعمل على: الاسم، الوصف، الوسوم، اسم الملف، والبرومبت.

```python
from taxonomy.safety import is_prompt_allowed, apply_safety_check

ok, hits = is_prompt_allowed("محارب بيكسل بسيف")
# ok=True

ok, hits = is_prompt_allowed("صورة النبي محمد")
# ok=False, hits=[...]
```

## ربطها بالموديل التوليدي

1. كل صورة في `data/` لها سجل في `labels_db.json`
2. قبل التدريب: `safety_check.status == "allowed"` فقط
3. الموديل الشرطي (لاحقاً) يستخدم التصنيفات كـ **conditioning** (labels / text)
4. عند التوليد: فحص البرومبت بنفس `is_prompt_allowed`

## تشغيل التهيئة

```bash
cd taxonomy
python3 bootstrap_labels.py
python3 safety.py   # اختبار سريع للحظر
```
