# All Data Trine - Pixel Art Dataset & Character Showcase

Welcome to the **All-data-Trine** dataset directory! This directory consolidates pixel art character assets, retro sprite sheets, animated GIFs, and showcase grids for model training, testing, and UI preview.

## Assets Included

### Cat Characters
- `ginger_cat_single.png`, `ginger_cat_spritesheet.png`
- `black_cat_single.png`, `black_cat_spritesheet.png`
- `siamese_cat_single.png`, `siamese_cat_spritesheet.png`
- `calico_cat_single.png`, `calico_cat_spritesheet.png`
- `master_cats_showcase.png` (256x256 composite showcase grid)

### Dog Characters
- `shiba_dog_single.png`, `shiba_dog_spritesheet.png`
- `husky_dog_single.png`, `husky_dog_spritesheet.png`
- `dalmatian_dog_single.png`, `dalmatian_dog_spritesheet.png`
- `cyber_dog_single.png`, `cyber_dog_spritesheet.png`
- `master_dogs_showcase.png` (256x256 composite showcase grid)

### Usage & Verification
All images are 64x64 or 256x64 RGBA retro pixel art sprites compatible with `pixel_art_engine` and ONNX mobile inference modules.
